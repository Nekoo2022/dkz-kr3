# Заметки — PWA

Веб-приложение для заметок. Текст хранится в `localStorage`. Оболочка приложения (HTML, CSS, JavaScript, манифест и иконки) кэшируется Service Worker, поэтому страница открывается и после отключения сети.

## Запуск

Нужен локальный сервер: Service Worker не работает, если открыть `index.html` двойным щелчком (`file://`).

Из корня этого проекта:

```bash
python3 -m http.server 8080
```

Откройте в Chrome или Edge:

```text
http://localhost:8080
```

Остановка сервера: `Ctrl+C` в том же терминале.

## Что проверить при сдаче

1. **Сеть есть.** Добавьте заметку и обновите страницу — текст на месте.
2. **Service Worker.** DevTools → Application → Service Workers: `sw.js`, статус activated.
3. **Cache Storage.** Application → Cache Storage → `notes-pwa-v1`: `index.html`, `styles.css`, `app.js`, `manifest.json`, иконки.
4. **Manifest.** Application → Manifest: имя «Заметки», `standalone`, цвета, иконки. Либо адрес `http://localhost:8080/manifest.json`.
5. **Установка.** Значок установки в адресной строке или кнопка «Установить» на странице. После установки приложение открывается в отдельном окне.
6. **Офлайн.** Application → Service Workers → Offline (или DevTools → Network → Offline). Обновите страницу: приложение открывается, старые заметки видны, новую можно добавить. Снимите Offline и обновите страницу ещё раз — новая заметка тоже на месте.

Перед проверкой офлайна один раз откройте приложение онлайн, чтобы Service Worker успел заполнить кэш.

## Как это устроено

**Service Worker** (`sw.js`) — скрипт, который браузер держит отдельно от страницы. При установке он сохраняет файлы оболочки в Cache Storage. Дальше запросы к этим файлам он закрывает из кэша и не ходит в сеть. Поэтому без интернета страница всё равно собирается.

**Web App Manifest** (`manifest.json`) описывает приложение для установки: имя, адрес запуска, режим `standalone` (без адресной строки браузера), цвета окна и иконки. Подключён в `index.html` через `<link rel="manifest">`.

**Офлайн.** Страница, стили и скрипт приходят из кэша. Заметки скрипт читает и пишет в `localStorage` на устройстве — этот вызов сети не требует. Данные привязаны к браузеру и адресу `localhost:8080`: другой браузер или другой порт увидят свой пустой список.

Кэш обновляется сменой `CACHE_NAME` в `sw.js`. После правки скриптов обновите страницу ещё раз, чтобы браузер подхватил новый Service Worker.
